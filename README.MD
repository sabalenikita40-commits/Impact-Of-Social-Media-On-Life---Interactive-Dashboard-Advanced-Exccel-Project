# 📊 Impact of Social Media on Life | Advanced Excel Project

## 📌 Project Overview

This project focuses on analyzing the impact of social media usage on students' daily lives using Microsoft Excel.

The analysis is based on a dataset of **4,500 students** and explores how social media usage influences sleep patterns, mental health, stress levels, lifestyle habits, and academic performance.

An interactive Excel dashboard has been developed to present key insights through Pivot Tables, Pivot Charts, and KPI Cards.

## 🎯 Project Objectives

- Analyze daily social media usage patterns among students.
- Identify the most popular social media platforms.
- Understand the relationship between social media usage and sleep duration.
- Analyze stress levels across different usage categories.
- Explore the impact of social media on academic performance.
- Examine late-night social media usage patterns.
- Present key findings through an interactive dashboard.

## 📈 Key Insights

Based on the Excel analysis:

- Total students analyzed: **4,500**
- Average daily social media usage: **5.30 hours**
- Average sleep duration: **6.70 hours**
- Average perceived stress score: **13.51**
- Late-night social media users: **2,644**
- Smartphone users: **3,775**
- Most popular platform: **Instagram (1,453 students)**
- Students reporting beneficial overall impact: **3,681**
